Git is a distributed version control system. GitHub is a cloud platform for hosting Git repositories.

## Basic Commands

```bash
git init
git add .
git commit -m "Initial commit"
git push origin main
```

## Branching

```bash
git checkout -b feature-branch
git merge feature-branch
```
